# Advance-Java-Servlet-IDE-Eclipse

This repository contains my Advanced Java Servlet practice projects developed using Eclipse IDE.

## Topics Covered

### 1. Java Basics
- Basic Java programs
- Variables and data types
- Operators
- Conditional statements
- Loops
- Methods
- Classes and objects

### 2. Web Application Basics
- Connecting Java applications with web pages
- HTML forms
- Sending form data to the server
- Request and response handling

### 3. Java Servlets
- Introduction to Servlets
- Servlet lifecycle
- HttpServlet
- doGet()
- doPost()
- HttpServletRequest
- HttpServletResponse
- Sending responses from Servlet
- Handling form data using Servlets

### 4. RequestDispatcher
- RequestDispatcher
- forward() method
- include() method
- Forwarding requests between resources
- Including the response of another resource

### 5. Page Redirection
- sendRedirect()
- Redirecting users from one page/Servlet to another

### 6. Cookies
- Creating cookies
- Setting cookies
- Reading cookies
- Cookie-based data handling
- Cookie expiration

### 7. URL Rewriting
- URL Rewriting concept
- Passing data through URLs
- URL-based session tracking
- Maintaining user information using URL Rewriting

## Projects

### First_Project
Contains basic Java programs and examples of connecting web pages and forms with Java.

### PageRedirectionDemo
Demonstrates page redirection using Servlets.

### Practice1_Project
Contains Servlet practice programs and examples of request handling.

### ServletC2Demo
Contains Servlet programs demonstrating request handling, web pages, forms and RequestDispatcher concepts.

### CookiesDemo
Demonstrates creating, setting and reading cookies using Java Servlets.

### UrlRewriteDemo
Demonstrates URL Rewriting and passing information through URLs.
